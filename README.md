# 🎨 Introduction to CSS

A beginner-friendly **HTML & CSS practice project** created to learn the fundamentals of CSS and understand how styling can be applied to an HTML webpage.

## 🌐 Live Demo

👉 [Open Introduction to CSS](https://basim-27.github.io/introducing-css-practice/)

## 📌 About The Project

This project introduces the basic concepts of **CSS (Cascading Style Sheets)** and demonstrates how CSS can be used to style HTML elements.

The webpage contains a short introduction to CSS along with an explanation of basic CSS syntax.

## 🛠️ Technologies Used

- 🟠 HTML5
- 🎨 CSS3

## ✨ CSS Concepts Practiced

- Universal selector `*`
- Element selectors
- Class selectors
- Background colors
- Text colors
- Font sizes
- Font families
- Text alignment
- Line height
- Font weight
- Font style
- RGB colors
- Linking an external CSS file
